# MATLAB Energy Consumption Tracker

A lightweight MATLAB tool for logging appliance usage, calculating real‑time and total energy consumption, and visualising usage patterns to help optimise household or lab energy efficiency.

---

## Features
- Track individual appliances with timestamps and power ratings  
- Automatic energy consumption calculation (kWh)  
- Real‑time and cumulative usage

  

## Getting Started
1. Clone the repository  
2. Add appliances and their power ratings  
3. Run `main.m`  
4. View generated logs and plots inside `/data`  

---

## Example Outputs
- Total daily energy usage  
- Appliance‑specific consumption charts  
- Peak usage hours
